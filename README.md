# Shattered Realms — Tactical Card Battler
A playable early prototype of a dark-fantasy turn-based card strategy game for mobile and desktop browsers.

## Run it
Open `index.html` in a modern browser.

## Host online
Upload `index.html` to a GitHub repository, then enable GitHub Pages using branch `main` and folder `/(root)`.

## Prototype features
- 7×7 tactical battlefield
- Player and enemy commanders
- Unit, spell, and equipment cards
- Mana, health, movement, attacks, turn progression
- Basic enemy AI and victory/defeat conditions
- Responsive mobile and desktop layout

This is a first prototype; the card balance, AI, and combat rules can be refined in later versions.
